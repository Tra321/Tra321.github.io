# 前言

首先感谢你能来访问我的 Blog，这是我搭建的第一个博客网站，使用的是 Github Pages + Hexo 的形式搭建。如果你也想搭建一个属于自己的博客，那么请继续往下看吧。

# 准备工作

搭建一个这样的 Blog 首先你得知道什么是 Github 和 Github Pages。我们需要将页面托管到了 Github 上。

## node.js

首先我们得先安装 node.js，进入node.js官网：[Node.js](https://nodejs.org/en/download/)

按照自己的操作系统选择对应的版本下载安装。

## Git

安装完 node.js 后，我们还需要安装 Git，进入 Git 官网：[Git](https://git-scm.com/downloads)

Git的学习方法推荐[廖雪峰的git教程](https://liaoxuefeng.com/books/git/introduction/index.html)

## 检验是否安装成功

同时按下Win键和R键打开运行窗口，输入`cmd`，打开命令行窗口，输入以下命令：

```bash
git --version
node -v
npm -v
```

如果提示“’node’ 不是内部或外部命令，也不是可运行的程序或批处理文件。”可尝试以管理员身份运行CMD后，输入以上命令，若不正确可以卸载软件重新安装。

# Hexo安装

## 本地生成博客内容

新建blog文件夹，进入blog文件夹，执行以下命令  
右键空白处点击Git Bash Here，输入

```bash
npm install hexo-cli -g
```

这个命令表示安装 hexo 的脚手架,如果错误可以尝试以管理员身份运行CMD后，输入以上命令。

在Git Bash中输入

```bash
hexo init
```

如果’conmmand not find’，则在前面加上npx，如： npx hexo init

## 本地查看博客内容

在blog文件夹下执行以下命令

```bash
hexo g 
hexo s 
```

执行完即可登录 [http://localhost:4000/](http://localhost:4000/) 查看效果

# 将Blog部署到Github

## 创建Github仓库

在github上新建一个仓库，仓库名为username.github.io，username为github用户名

在blog文件夹下找到\_config.yml文件，修改以下内容

```bash
deploy:
  type: git
  repo: https://github.com/username/username.github.io.git
  branch: master
```

安装自动部署发布工具

```text
npm install hexo-deployer-git --save
```

执行以下命令上传到Github

```bash
hexo d
```

## 更新博客内容

在blog文件夹下执行以下命令

```bash
hexo cl
hexo g
hexo d
```
