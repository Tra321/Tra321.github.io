# Windows安装Docker

windows系统必须高于1904版本  
window安装Docker必备的的条件：Hyperv和WSL2  
如果没有准备好直接安装Docker Desktop,就会出现  
![](/images/posts/20250219161856371.png)

## 1.安装Hyper-V

其中Windows11家庭中文版没有Hyper组件，需要运行一个处理程序来启动Hyper-V组件

将以下代码复制到记事本中，并另存为install\_hyper\_v.cmd，然后右键该脚本，通过“管理员模式运行”

```bash
pushd "%~dp0"
dir /b %SystemRoot%\servicing\Packages\*Hyper-V*.mum >hyper-v.txt
for /f %%i in ('findstr /i . hyper-v.txt 2^>nul') do dism /online /norestart /add-package:"%SystemRoot%\servicing\Packages\%%i"
del hyper-v.txt
Dism /online /enable-feature /featurename:Microsoft-Hyper-V-All /LimitAccess /ALL
```

运行结束后会提示重启电脑，输入Y后回车重启电脑。

重启后打开控制面板，点击程序，再程序和功能内找到启动或关闭Windows功能，勾选Hyper-V、Windows虚拟机监控程序平台、适用与Linux的Windows子系统、虚拟机平台，点击确定后重启电脑

## 2.安装WSL2

打开WLS2手动升级包下载页面[https://learn.microsoft.com/zh-cn/windows/wsl/install-manual](https://learn.microsoft.com/zh-cn/windows/wsl/install-manual)

找到‘适用于下载x64计算机的WLS2Linux内核升级包’下载wsl\_update\_x64.msi，双击安装，安装完成后重启电脑

## 3.安装Docker Desktop

打开Docker官网下载页面[https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop)

选择Windows版本下载，下载完成后双击安装包，安装完成后重启电脑

视频教程可参考[Windows安装Docker Desktop教程](https://www.bilibili.com/video/BV13h6mYbEmy/?spm_id_from=333.1007.top_right_bar_window_history.content.click&vd_source=024d564069dcc44f5f443e05b09b842f)

# CentOS安装Docker

以下教程再CentOS 7.9 64位上操作

本安装教程参考Docker官方文档，地址如下：[https://docs.docker.com/engine/install/centos/](https://docs.docker.com/engine/install/centos/)

## 1\. 卸载旧版本

首先如果系统中已经存在旧的Docker，则先卸载：

```shell
yum remove docker \
    docker-client \
    docker-client-latest \
    docker-common \
    docker-latest \
    docker-latest-logrotate \
    docker-logrotate \
    docker-engine \
    docker-selinux 
```

## 2.配置Docker的yum库

首先要安装一个yum工具

```bash
sudo yum install -y yum-utils device-mapper-persistent-data lvm2
```

安装成功后，执行命令，配置Docker的yum源（已更新为阿里云源）：

```bash
sudo yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

sudo sed -i 's+download.docker.com+mirrors.aliyun.com/docker-ce+' /etc/yum.repos.d/docker-ce.repo
```

更新yum，建立缓存

```bash
sudo yum makecache fast
```

## 3.安装Docker

最后，执行命令，安装Docker

```bash
yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

查看Docker版本

```bash
docker -v
```

```bash
docker images
```

因为没有启动docker，则提示无法连接到Docker daemon

## 4.启动和校验

```bash
# 设置开机自启
systemctl enable docker

# 启动Docker
systemctl start docker

# 执行docker ps命令，如果不报错，说明安装启动成功
docker ps
```

```bash
# 停止Docker
systemctl stop docker

# 重启
systemctl restart docker
```

## 5.配置镜像加速

镜像地址可能会变更，如果失效可以百度找最新的docker镜像。  
配置镜像步骤如下：

```bash
# 创建目录
mkdir -p /etc/docker

# 复制内容
tee /etc/docker/daemon.json <<-'EOF'
{
    "registry-mirrors": [
        "http://hub-mirror.c.163.com",
        "https://mirrors.tuna.tsinghua.edu.cn",
        "http://mirrors.sohu.com",
        "https://ustc-edu-cn.mirror.aliyuncs.com",
        "https://ccr.ccs.tencentyun.com",
        "https://docker.m.daocloud.io",
        "https://docker.awsl9527.cn"
    ]
}
EOF

# 重新加载配置
systemctl daemon-reload

# 重启Docker
systemctl restart docker
```

如果是阿里云服务器，可以在阿里云容器镜像服务的镜像工具中找到镜像加速器，通过修改daemon配置文件/etc/docker/daemon.json来使用加速器，如下：

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://oono4g7w.mirror.aliyuncs.com"]
}
EOF
sudo systemctl daemon-reload
sudo systemctl restart docker
```

## 6.安装Docker Compose

github上找到Docker Compose并下载上传服务器

```bash
cp docker-compose-linux-x86_64 /usr/local/bin/docker-compose
```

```bash
chmod +x /usr/local/bin/docker-compose
```

测试是否安装成功

```bash
docker-compose --version
```
