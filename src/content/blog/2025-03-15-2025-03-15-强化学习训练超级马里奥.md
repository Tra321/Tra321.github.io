> 项目源代码已放到github上，[传送门](https://github.com/Tra321/Super_Mario)

## 1\. 环境安装

### 1.安装Anaconda

1.新建环境

> 用pycham创建一个空项目，在GitHub上将requirements.txt复制到项目中

打开Anaconda prompt，创建新环境 python版本支持3.8

```text
conda create -n Mario python==3.8.8
```

### 2.激活环境

```text
conda activate Mario
```

### 3.安装依赖

```text
pip install setuptools==65.5.0
pip install wheel==0.38.4

pip install pip==20.2.4
python.exe -m pip install pip==20.2.4

cd D:\Super_Mario\ # 进入requirements.txt所在的目录
pip install -r requirements.txt
```

> 由于下载的torch 轮子版本是cpu的，无法调用gpu，所以需要重新下载gpu版本的[torch](https://download.pytorch.org/whl/torch_stable.html)

我下载的是torch-2.0.0+cu118-cp38-cp38-win\_amd64.whl，对应python3.8,在Anaconda prompt中cd到所下载的文件夹，然后执行

```text
pip install torch-2.0.0+cu118-cp38-cp38-win_amd64.whl
```

## 2\. 测试依赖

打开pycharm，在项目根目录下创建一个test\_Mario.py文件，输入以下代码

```python
from nes_py.wrappers import JoypadSpace
import gym_super_mario_bros
from gym_super_mario_bros.actions import SIMPLE_MOVEMENT
env = gym_super_mario_bros.make('SuperMarioBros-v0')
env = JoypadSpace(env, SIMPLE_MOVEMENT)

done = True
for step in range(5000):
    if done:
        state = env.reset()
    state, reward, done, info = env.step(env.action_space.sample())
    env.render()

env.close()
```

> 直接运行，如果出现马里奥在屏幕上跑动，则说明环境配置成功
