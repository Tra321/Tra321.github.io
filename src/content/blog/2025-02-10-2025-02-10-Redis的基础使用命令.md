## 运行Redis服务端

打开Redis安装目录，在文件资源管理器中打开命令行。

```cmd
redis-server.exe redis.windows.conf
```

关闭服务器

```cmd
^C
```

## 运行Redis客户端

打开Redis安装目录，在文件资源管理器中打开命令行。

```cmd
redis-cli.exe -h localhost -p 6379 -a 123456
```

密码在redis.windows.conf中设置 找到requirepass字段，关闭注释，设置密码为requirepass 123456

关闭客户端

```cmd
exit
```

## Redis常用命令

### Redis字符串命令

```cmd
set key value # 设置指定 key 的值

get key # 获取指定 key 的值

keys * # 查看所有key

setnx key seconds value # 为给定 key 设置过期时间

ttl key # 查看给定 key 的剩余生存时间

setnx key value # 只有在 key 不存在时设置 key 的值
```

### Redis哈希命令

```cmd
hset key field value # 将哈希表 key 中的字段 field 的值设为 value

hget key field # 获取存储在哈希表中指定字段的值

hdel key field # 删除储存在哈希表中指定的字段

hkeys key # 获取所有哈希表中的字段

hvals key # 获取哈希表中所有的值
```

### Redis列表命令

```cmd
lpush key value1 [value2] # 将一个或多个值插入到列表头部

rpush key value # 在列表尾部添加一个或多个值

lrange key start stop # 获取列表指定范围内的元素

lpop key # 移除并返回列表的第一个元素

rpop key # 移除并返回列表的最后一个元素

llen key # 获取列表长度
```

### Redis集合命令

```cmd
sadd key member1 [member2] # 向集合添加一个或多个成员

smembers key # 返回集合中的所有成员

scard key # 获取集合的成员数

sinter key1 [key2] # 返回给定所有集合的交集

sunion key1 [key2] # 返回所有给定集合的并集

srem key member1 [member2] # 移除集合中一个或多个成员
```

### Redis有序集合命令

```cmd
zadd key score1 member1 [score2 member2] # 向有序集合添加一个或多个成员，

zrange key start stop [WITHSCORES] # 通过索引区间返回有序集合成指定区间内的成员

zincrby key increment member # 对有序集合中指定成员的分数加上增量 increment

zrem key member [member ...] # 移除有序集合中的一个或多个成员
```

### Redis通用命令

```cmd
keys pattern # 查找所有符合给定模式 pattern 的 key

exists key # 检查给定 key 是否存在

type key # 返回 key 所储存的值的类型

del key [key ...] # 删除一个或多个 key
```
